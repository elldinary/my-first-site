# 쉬운 사주 (easy-saju)

생년월일시를 넣으면 사주를 **초등학생도 이해하는 쉬운 말**로 풀어 주는 웹 서비스.
PRD("쉬운 사주 리포트 서비스") 기반 + 비즈니스 모델(무료 맛보기 → 상세 리포트 19,000원) 적용 버전.

## 구조 (빌드 없는 정적 사이트 — GitHub Pages에서 바로 동작)

```
/saju
  index.html        # 입력 화면 + 리포트 화면 (SPA)
  saju.css          # 스타일 (오행 색 팔레트는 접근성 검증 통과값)
  /js
    engine.js       # 계산 엔진: 절기(태양 황경)·태양시 보정·야자시·십성·운성·신살·용신
    report.js       # 해석 규칙 + 용어 치환 사전 + 쉬운 문장 템플릿
    app.js          # 화면 + 페이월/결제 흐름
  /tests
    run-tests.mjs   # PRD §9.4 레퍼런스 명식 회귀 테스트 (AC1·AC4·AC6)
    copy-lint.mjs   # 카피 자동 검수: 한자·전문용어·60자 초과·팁 누락 (AC3·AC5)
```

## 테스트

```bash
node saju/tests/run-tests.mjs
```

레퍼런스 명식 A(1992-12-16 申시)·B(1995-12-18 辰시)의 사주팔자·십성·십이운성·신살·
신강신약·용신 전 항목 일치 + 입춘/야자시 경계 + 시간 모름 + 카피 린트를 검사한다.

## 비즈니스 모델

- **무료(맛보기)**: 명식 카드, "한마디로 나는?", 오행 분포 그래프, 장점 1개 티저
- **유료(상세, 19,000원 / 정가 39,000원 표기)**: 장점·조심할 점(+팁), 용신/기신,
  신강신약, 생활 스타일, 겉모습 vs 속마음, 십성 요약, 3개월 신호등, 2인 궁합
- 잠금 해제는 `localStorage`에 사주 입력값 기준으로 저장 → 같은 입력이면 재열람 가능

## PRD 대비 결정 사항

- **스택**: 이 저장소가 정적 호스팅이라 Next.js 모노레포 대신 무빌드 정적 SPA로 구현.
  레이어 분리(엔진/리포트/화면)는 PRD §3.2 구조를 그대로 따름.
- **만세력 라이브러리 대신 자체 절기 계산**: npm 빌드가 없는 환경이라 태양 황경
  직접 계산(Meeus 공식, 절입 오차 수 분 이내)을 쓰고, PRD가 요구한 레퍼런스 명식
  회귀 테스트로 정확도를 검증함. 라이브러리 도입 시 engine.js 래퍼만 교체하면 됨.
- **자시 처리**: PRD 열린 결정 §12-1의 권장대로 **야자시 기준 고정**
  (23~24시는 당일 날짜 유지 + 자시).
- **신살 기준**: 레퍼런스 명식과 일치하는 **일지 삼합 기준** 12신살.
- **문장 렌더**: Claude API 다듬기(§6.3)는 옵션이므로 v1은 규칙 템플릿만 사용
  (비용 0, 결과 일관). 전 문장이 카피 린트 게이트를 통과함.
